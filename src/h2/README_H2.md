## 1. H2 가설 및 실험 목적

**H2: 통화정책 변화에 대한 기업별 주식수익률 반응은 부채 특성에 따라 차이가 있을 것이다.**

기존 H2에서는 한국은행 통화정책방향 문서에서 추출한 정책 기조(PolicyScore)와 기업 부채비율(Debt)을 중심으로 분석하였다.

이후 변수 확장이 필요하다는 피드백을 반영하여 **기업의 부채 변화, 통화정책 기조 변화, 실제 기준금리 변화 및 상호작용항을 추가**하였다.

최종적으로 H2 전용 변수 8개를 구성하고, 이 변수들만을 사용하여 월별 주식수익률의 횡단면 순위를 예측하는 실험을 수행하였다.

## 2. H2 변수 구성

| 구분 | 변수 | 설명 |
| --- | --- | --- |
| 기업 재무 | Debt | 기업의 부채비율 |
| 기업 재무 | DebtChange | 이전 이용 가능 재무보고서 대비 부채비율 변화 |
| 통화정책 | PolicyScore | 한국은행 통화정책방향 문서의 정책 기조 점수 |
| 통화정책 | PolicyChange | 전월 대비 정책 기조 점수 변화 |
| 통화정책 | RateChange | 전월 대비 실제 정책금리 변화 |
| 상호작용 | PolicyScore × Debt | 정책 기조와 부채비율 간 상호작용 |
| 상호작용 | PolicyChange × Debt | 정책 기조 변화와 부채비율 간 상호작용 |
| 상호작용 | RateChange × Debt | 실제 금리변화와 부채비율 간 상호작용 |

총 **8개 변수(기본·파생변수 5개, 상호작용항 3개)**를 사용하였다.

부채비율은 기존 DART·DataGuide Hybrid 자료를 활용했으며, DebtChange는 이전에 이용 가능했던 서로 다른 재무보고서 간 부채비율 차이로 생성하였다. RateChange는 한국은행의 실제 정책금리 변동 이력을 사용하였다.

## 3. 실험 방법

| 항목 | 설정 |
| --- | --- |
| 검증 기간 | 2006년 1월~2021년 12월 |
| 검증 방식 | 연도별 Expanding Window |
| 학습 데이터 | 검증 연도 이전의 과거 데이터 |
| 예측 대상 | 다음 달 종목별 조정수익률 |
| 모델 | Ridge, Random Forest, XGBoost, LightGBM |
| 평가 지표 | 월별 Spearman RankIC |
| 평가 개월 수 | 192개월 |
| 평가 관측치 | 127,622행 |

연도별 Expanding Window 방식으로 과거 데이터를 누적 학습하고, 해당 검증 연도의 12개월을 평가하였다.

모든 모델에 동일한 H2 변수 8개를 사용하였으며, 다른 가설인 H1·H3의 변수는 모델 입력에 포함하지 않았다.

또한 2022~2025년 최종 테스트 데이터는 사용하지 않았다.

## 4. H2 단독 모델 성능

| 모델 | 평균 RankIC | 중앙값 RankIC | IC 양수 월 비율 |
| --- | --- | --- | --- |
| **Random Forest** | **0.00841** | 0.00808 | 53.13% |
| LightGBM | 0.00561 | 0.00621 | 55.73% |
| XGBoost | 0.00520 | 0.00447 | 52.60% |
| Ridge | 0.00323 | 0.00664 | 52.08% |

**Random Forest가 평균 RankIC 0.00841로 가장 높은 성능**을 기록하였다.

다만 전체 모델의 평균 RankIC가 0.01 미만으로 나타나, H2 변수만 사용했을 때는 종목별 미래 수익률 순위를 예측하는 능력이 제한적인 것으로 확인되었다.

Random Forest의 월별 RankIC가 양수인 비율도 53.13%(192개월 중 102개월)로, 지속적이고 안정적인 양의 예측력을 확보했다고 보기는 어렵다.

추가로 Random Forest의 월별 평균 RankIC가 0보다 큰지 HAC(6) 양측 검정을 수행한 결과, p-value는 약 0.0627로 나타났다. 따라서 일반적인 5% 유의수준에서 평균 RankIC가 0보다 크다는 통계적 근거는 충분하지 않았다.

## 5. 결과 해석

이번 실험에서는 기업의 부채 수준과 변화, 통화정책 기조 및 실제 금리변화, 그리고 정책·부채 상호작용을 모두 고려하였다.

Random Forest가 가장 높은 성능을 기록한 점은 이러한 정보가 비선형 모델에서 일정 부분 활용될 가능성을 보여준다. 다만 모델 간 성능 차이만으로 비선형 관계가 입증됐다고 해석하기는 어렵다.

또한 H2 단독 모델은 기업의 통화정책 민감도를 설명하기 위한 변수들로 구성되어 있으므로, 규모·가치·모멘텀·변동성 등 일반적인 주식수익률 예측요인을 포함한 모델에 비해 예측정보가 제한적일 수 있다.

따라서 **H2의 독립적 예측력에는 한계가 있으나, 다른 기업 특성 변수와 결합했을 때 추가적인 정보를 제공하는지는 별도 검증이 필요하다**고 판단하였다.

## 6. 향후 계획

**① 하이퍼파라미터 튜닝**

현재 모델은 고정된 하이퍼파라미터로 학습하였다. 향후 Random Forest, XGBoost, LightGBM의 트리 깊이(max_depth), 트리 개수(n_estimators) 등을 조정하고 내부 시계열 검증으로 성능을 비교할 예정이다.

**② H1·H3와의 통합 효과 검증**

H2의 8개 변수를 모두 유지하면서 H1·H3의 기본 변수 4개를 추가한 통합 모델을 별도로 평가한다. 이를 통해 H2의 독립적 예측력과 기존 가설에 대한 추가 기여를 구분한다.

**③ 최종 예측 적용**

검증 결과를 바탕으로 모델 설정을 확정한 후, 2022~2025년 최종 예측에 적용할 계획이다.

또한 기존 Hybrid 재무자료가 완전한 과거 시점 기준(PIT) 원본 이력을 보장하지 않는다는 점을 고려하여, 데이터 이용 가능 시점과 재현성을 지속적으로 점검할 예정이다.

## 7. 결론

H2에서는 변수 확장 피드백을 반영하여 기존 부채비율·통화정책 기조 중심의 구성에서 총 8개 변수로 확장하였다.

2006~2021년 Expanding Window 검증 결과 Random Forest가 평균 RankIC 0.00841로 가장 높은 성능을 보였으나, H2 변수만으로는 안정적인 수익률 순위 예측력을 확보하는 데 한계가 있었다.

따라서 이후에는 **트리 기반 모델의 하이퍼파라미터 튜닝을 통해 예측 성능 개선 가능성을 확인하고, H1·H3 통합 모델에서 H2 변수의 추가 기여를 검증할 계획**이다.
