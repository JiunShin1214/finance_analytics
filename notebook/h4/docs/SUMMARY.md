# H4 분석 결과 요약 — 2026-11-16

## 가설과 입력

경제정책 불확실성이 높은 달에는 모멘텀과 차월 수정 월수익률의 양의 관계가 약해지는지 검정한다.
Cho–Kim(2023)의 한국 EPU 지수를 기준월 t의 직전 월(t−1)로 연결하고, 팀 제공 mom.parquet의 원 11개월 MOM을 재사용한다. EPU·MOM·상호작용을 보존한다. EPU 자료는 사용자가 검증 완료했다고 확인했다. 기사를 직접 수집하지 않는다.

## 결론과 해석 범위

2단계 윈저 분석에는 음의 관계에 대한 미보정 근거가 있지만, 패널 검정과 원값 민감도 결과는 일관된 유의성을 보이지 않는다. H4가 확정 지지됐다고 결론내리지 않는다. 전체 가설군 Holm 보정은 후속 작업이다.
양수 월별 EPU×MOM은 MOM과 횡단면 순위가 같으므로 직접 IC는 EPU의 추가 예측력을 입증하지 않는다. H1 기준 대비 결합모형 평가·공식 model_test 결과는 팀 후속 작업이다.

## 팀 전달 사항

모델 입력은 `python -m src.team.dan.h4_export`로 재생성한다. 생성 파일은 data/processed/dan_h4_epu.parquet이며 Git에 포함하지 않는다. 최신 공통 prepare_inputs의 extra_features에 원 MOM·EPU·상호작용을 상대 data/ 경로와 transform=none으로 전달한다. 기존 MOM과의 중복 열·공통 학습/평가 표본·스케일링은 결합 단계에서 확인한다.
