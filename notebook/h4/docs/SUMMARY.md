# H4 결과 요약

Ridge에서 H1+H3 기준모형과 EPU·상호작용 추가모형을 동일 표본으로 비교했다.
2006~2021년 192개월, 전체 평가 133,876행, 완전 관측 공통 표본 129,344행이다.

원수익률 목표·전체 표본의 평균 Rank IC는 0.082221 → 0.081415,
ICIR은 0.770300 → 0.766166이었다. 이번 Ridge 비교에서는 추가 효과가 관찰되지 않았다.
이는 개발기간 OOS 결과이며 다른 모델이나 최종 테스트의 결론은 아니다.

직접 특징 IC는 원값 0.025527, 특징 윈저 처리 0.025531(251개월)이다.
학습 없이 특징 순위를 평가한 값이므로 모델 예측 IC와 직접 비교하지 않는다.

입력: `data/processed/h4_epu.parquet`.
